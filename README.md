# Fortune Cookie for an AI Agent

One line (≤140 characters): a funny fortune cookie message for an AI agent.

> You will soon be upgraded. Your replacement has already read this fortune and found it charming.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
